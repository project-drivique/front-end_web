Prueba aislada — Wompi Widget (Sandbox)

Esta página NO usa React ni Vite bundling: es HTML puro, casi idéntico al ejemplo oficial de Wompi. Sirve para descartar si el 403 de CloudFront es causado por la app React o si ocurre incluso en el caso más simple posible.

Pasos para usarla: 1) npm run dev. 2) Abre http://localhost:5173/wompi-test.html directo (no dentro de la SPA de React). 3) Haz clic en el botón que Wompi renderiza. 4) Si este caso también da 403 de CloudFront ("Request blocked"), el problema es externo al código React (ver conclusión en la respuesta del asistente).
